# SPECTRE STUDIO — сайт-портфолио

Статичный сайт: обычные HTML, CSS и JS. Сервер, база данных и оплата хостинга не нужны.
Работает на ПК и телефоне, есть русский и английский язык (переключатель RU/EN в шапке).

```
spectre-studio/
├── index.html          ← страница
├── css/style.css       ← дизайн (цвета в самом начале файла, блок :root)
├── js/app.js           ← логика и ВСЕ ТЕКСТЫ сайта на RU/EN (объект I18N)
├── data/works.js       ← СПИСОК РАБОТ  ← правите здесь
├── data/reviews.js     ← СПИСОК ОТЗЫВОВ ← правите здесь
├── assets/logo.webp    ← логотип студии
└── works/              ← файлы работ по папкам
    ├── avatars/  banners/  animations/  previews/  bots/
```

## Как добавить работу

1. Положите файл в нужную папку, например `works/avatars/ava-07.webp`.
   - Картинки: `.webp`, `.jpg` или `.png`, лучше до 500 КБ (сжать можно на https://squoosh.app).
   - Анимации: `.mp4` или `.webm` (до ~5 МБ) или `.gif`.
2. Откройте `data/works.js` и добавьте строку в нужный раздел:

```js
{ cat: "avatars", src: "works/avatars/ava-07.webp", title: "Ава для стримера", title_en: "Streamer avatar" },
```

Значения `cat`: `avatars` (аватарки), `banners` (баннеры), `animations` (анимации), `previews` (превью), `bots` (боты и системы).
Подписи `title` и `title_en` можно не указывать.

Бот или система (картинка не обязательна):

```js
{ cat: "bots", title: "Бот для магазина", title_en: "Shop bot",
  text: "Что умеет бот…", text_en: "What the bot does…",
  tags: ["Python", "aiogram"], link: "https://t.me/your_bot" },
```

Имена файлов пишите латиницей и без пробелов (`dengiz.webp`, а не `Денгиз (2).png`). Иначе на некоторых хостингах файл может не открыться.

Исходники в полном качестве лежат отдельно, в папке `E:\ClaudeОпенмонтаж\spectre-originals`. На сайт их загружать не нужно.

## Как добавить отзыв

В `data/reviews.js` скопируйте любой блок и поменяйте поля: `id` (номер поста в t.me/specreview), `name`, `date`, `ru`, `en`.

## Как поменять тексты

Все надписи сайта на обоих языках собраны в `js/app.js`, в объекте `I18N`: `ru: {...}` и `en: {...}`.

Ссылку на сайт можно открыть сразу на нужном языке: `…/?lang=en` или `…/?lang=ru`.
Без параметра язык выбирается по языку браузера посетителя, а потом запоминается.

## Бесплатная публикация

### Вариант 1. GitHub Pages (рекомендую: работы можно добавлять прямо в браузере)

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **New repository** и назовите его, например, `spectre-studio`. Тип: **Public**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите **содержимое** папки `spectre-studio` (не саму папку: `index.html` должен оказаться в корне). Затем нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В поле **Source** выберите `Deploy from a branch`, затем ветку `main` и папку `/ (root)`. Нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ_НИК.github.io/spectre-studio/`.

**Добавить работу потом:** откройте папку, например `works/avatars`, и выберите **Add file → Upload files**. Затем откройте `data/works.js`, нажмите на карандаш (Edit), добавьте строку и нажмите **Commit**. Сайт обновится сам примерно через минуту.

### Вариант 2. Netlify Drop (быстрее всего, без Git)

Зайдите на https://app.netlify.com/drop и перетащите папку `spectre-studio`. Вы сразу получите ссылку.
Чтобы обновить сайт, снова перетащите папку в разделе **Deploys** вашего сайта.

### Вариант 3. Cloudflare Pages

https://pages.cloudflare.com → **Create → Pages → Upload assets**, затем перетащите папку. Тоже бесплатно, есть быстрый CDN.

Свой домен (например `spectre.studio`) можно подключить в любом из вариантов. Хостинг останется бесплатным, платить нужно только за сам домен.
